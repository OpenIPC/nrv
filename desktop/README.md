# Десктоп-приложение

Приложение для рабочих мест операторов на Windows. Собирается
автоматически: готовый архив лежит во вкладке **Actions** на GitHub.

Общее описание и причины выбора технологии — в `docs/DESKTOP.md`.

## Что уже работает

- Вход с указанием адреса сервера, логина и пароля.
- Запоминание адреса и логина между запусками.
- Токен хранится зашифрованным (привязан к учётной записи Windows).
- Список камер с состоянием: в сети или нет.
- Окно просмотра камеры для каждой камеры.
- Разговор через динамик камеры **без повторных запросов разрешения**.
- Перенос окна на другой монитор кнопкой в заголовке.
- Запоминание монитора и положения каждого окна.

## Как получить готовое приложение

1. Откройте репозиторий на GitHub.
2. Перейдите во вкладку **Actions**.
3. Выберите слева **Сборка десктоп-приложения**.
4. Откройте последний запуск (зелёная галочка).
5. Скачайте **NvrDesktop-win-x64** внизу страницы.

Распакуйте архив и запустите `NvrDesktop.exe`. Устанавливать ничего не
нужно: .NET и всё остальное уже внутри.

## Сборка вручную

Нужна машина с Windows и .NET 8 SDK. WPF не собирается на Linux.

```
cd desktop
dotnet publish src/NvrDesktop/NvrDesktop.csproj -c Release -r win-x64 --self-contained true -o ./publish
```

Готовый файл: `desktop/publish/NvrDesktop.exe`.

## Требования

- **Windows 10 или 11.**
- **WebView2 Runtime.** В Windows 11 он уже установлен. Для Windows 10
  скачайте «Evergreen Standalone Installer» с сайта Microsoft —
  он ставится один раз и не требует прав администратора.

Без WebView2 приложение запустится и покажет понятное сообщение о том,
чего не хватает, — окно камеры просто не откроется.

## Настройки и данные

Всё лежит в профиле пользователя:

```
%APPDATA%\NvrDesktop\settings.json   — адрес сервера, логин, положение окон
%APPDATA%\NvrDesktop\token.bin       — токен доступа (зашифрован)
%LOCALAPPDATA%\NvrDesktop\WebView2\  — кэш встроенного браузера
```

Пароль нигде не сохраняется. Токен зашифрован и привязан к учётной
записи: скопировать файл на другую машину и войти с него нельзя.

## Как это устроено

Оболочка на C# (WPF) плюс встроенный браузер (WebView2) с обычным
веб-интерфейсом внутри. Плеер, архив, события и панель разговора —
это существующие страницы, они не переписывались.

Оболочка берёт на себя то, чего браузер не даёт: окна на нескольких
мониторах, защищённое хранение токена и разрешения без повторных
подтверждений.

```
src/NvrDesktop/
├── App.xaml, App.xaml.cs           — запуск, вход по сохранённому токену
├── Services/
│   ├── ApiClient.cs                — запросы к серверу, вход
│   ├── TokenStore.cs               — шифрованное хранение токена
│   └── SettingsStore.cs            — настройки и положение окон
└── Windows/
    ├── LoginWindow.xaml            — вход: адрес сервера, логин, пароль
    ├── MainWindow.xaml             — список камер
    ├── CameraWindow.xaml           — просмотр камеры
    └── WindowManager.cs            — мониторы и запоминание положения
```
