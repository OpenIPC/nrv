# Установка с ISO (автоматическая)

Как собрать образ, с которого система и сервер ставятся без вопросов: загрузились
с флешки — через несколько минут работает видеонаблюдение. Это заготовка для
установки на объектах без интернета; сборка комплекта поставки (образы Docker,
пакеты, модели) описана в [BUNDLE.md](BUNDLE.md) — её можно вложить в этот образ
одним ключом `--bundle`.

## Что нужно

- образ Debian netinst (`debian-12.x-amd64-netinst.iso`, около 700 МБ);
- файл ответов мастера (`/root/nvr-answers.conf`, его пишет
  `scripts/nvr-install.sh`) — из него берутся имя машины, часовой пояс, сервер
  времени и адрес в сети;
- `xorriso` и `isolinux` на машине сборки:

```bash
sudo apt-get install -y xorriso isolinux
```

## Сборка

```bash
sudo ./scripts/make-iso.sh \
    --base /путь/debian-12.13.0-amd64-netinst.iso \
    --answers /root/nvr-answers.conf \
    --root-key /root/.ssh/id_ed25519.pub \
    --out /var/lib/vz/template/iso/nvr-auto.iso
```

Рядом с образом сохраняется файл `nvr-auto.password` — пароль root для входа в
консоль. Пароль не задан параметром, поэтому генерируется случайным: один и тот
же пароль на всех объектах недопустим, а записать его в репозиторий нельзя.

## Установка

```bash
qm set 113 --ide2 local:iso/nvr-auto.iso,media=cdrom
qm set 113 --boot order=ide2;scsi0
qm start 113
```

На флешку: `dd if=nvr-auto.iso of=/dev/sdX bs=4M status=progress oflag=sync`.

Установка идёт без вопросов: система ставится сама, загрузочный диск извлекается,
в конце скачиваются исходники сервера в `/root/nvr`. Дальше подключаются по SSH
и запускают мастер:

```bash
ssh root@<адрес>
/root/nvr/scripts/nvr-install.sh
```

## Что подставляется из ответов

| Ключ ответов | Куда идёт |
|---|---|
| `NVR_HOSTNAME` | имя машины |
| `NVR_TZ` | часовой пояс системы |
| `NVR_NTP_SERVERS` | первый сервер времени (остальные допишет мастер) |
| `NVR_NET_MODE`, `NVR_NET_IP`, `NVR_NET_GATEWAY`, `NVR_NET_DNS` | адрес: постоянный или DHCP |
| `NVR_REPO_URL` | откуда взять исходники после установки |

## Что проверено и почему сделано именно так

Проверено на Debian 12.13.0 (образ netinst, узел Proxmox).

- **Пароль root обязателен.** Без `passwd/root-password` установщик встаёт на
  вопросе «Set up users and passwords» и ждёт ввода: автоматическая установка не
  идёт вовсе. Приоритет `critical` этот вопрос не отменяет.
- **`passwd/make-user boolean false`.** Иначе установщик спрашивает имя и пароль
  пользователя — и снова останавливается.
- **Записи загрузки лежат не в `isolinux.cfg`.** В Debian 12 там только
  `include menu.cfg`, а сами записи — в `txt.cfg` (текстовое меню) и `gtk.cfg`
  (графическое). Если править один `isolinux.cfg`, автозапуск не добавится, а
  образ соберётся и будет выглядеть готовым.
- **`default install` и `timeout 30`.** Меню BIOS ждёт выбора бесконечно
  (`timeout 0`), и на объекте установка не началась бы: у экрана никто не стоит.
- **`cdrom-detect/eject boolean true`.** Без этого машина после установки
  загружается с образа снова и ставит систему поверх себя же.
- **Один `preseed/late_command`.** Если записать его дважды, установщик возьмёт
  последнюю запись, и первая (ключ доступа по SSH) молча потеряется.
